Licensing FAQ

Is PDFBay really free?

Yes. Every tool on this site is free to use without registration, and the software itself is free under AGPL-3.0. There is no paid tier and nothing to buy.

Can I use PDFBay commercially?

Yes. AGPL-3.0 software may be used for commercial purposes. If you distribute a modified version or offer it to users over a network, you must make your modified source code available under AGPL-3.0.

Can I use PDFBay in a closed-source product?

Only if your use does not require distributing or network-serving a modified version to others. The AGPL obligations apply to modifications of this code, not to documents you create with the tools. If you need a proprietary license, contact the original BentoPDF authors — PDFBay itself does not sell licenses.

Why does PDFBay credit BentoPDF?

Because PDFBay is built on BentoPDF, an open-source project also released under AGPL-3.0. AGPL-3.0 requires that we keep the original copyright notice and license, and that we make our source code available — both are satisfied here.

Where can I get the source code?

The complete source is on GitHub, including this license file and the original upstream notice.
